1. Executive Summary & Platform Context

TenderHub is a unified, high-speed discovery and bidding management portal for civil, electrical, and infrastructure contractors across all 20 districts of Jammu & Kashmir.

The platform aggregates public notices from the official e-procurement gazette (jktenders.gov.in) and solves the major usability issues contractors face on the government site:

  • Short Session Logouts: Bidders get auto-logged out every 10 minutes on the official portal. TenderHub provides continuous browsing with persistent bookmarks.
  • Unusable Mobile Experience: Government tables do not work on mobile phones. Contractors need a mobile-first UI for review on construction sites.
  • Hidden Attachments: Bill of Quantities (BOQ) Excel sheets and technical drawings are nested inside complex menus. TenderHub surfaces them directly.
  • Ambiguous Work Locations: TenderHub extracts specific project sites, tehsils, and districts, providing direct map navigation.
Designer Note on Creative Freedom
The UI/UX designer has complete creative freedom to choose the color theme, visual styling, brand aesthetics, and typography. The requirements below specify the functional purpose, content hierarchy, data fields, and user workflows for each screen.

3. Functional UI & UX Requirements

  • Outdoor Legibility: Contractors frequently read screens outdoors under direct sunlight. Ensure strong visual contrast, clear headings, and readable font weights.
  • Tabular & Financial Precision: Tender reference IDs, dates, and currency values in Indian Rupees (₹) must use clean tabular numerals or monospace styling for instant scanning.
  • Touch Targets: All buttons, dropdowns, and filter pills must be touch-friendly on mobile screens (minimum 44×44px hit areas).
  • Responsive Layouts: Full support for Mobile (375px+), Tablet (768px), and Desktop (1280px+).
  • Light & Dark Modes: Both clean high-contrast light mode and eye-friendly dark mode for evening/night work.

4. Comprehensive Page-by-Page Specifications & Content Details

Page 1: Homepage
Route: /

Screen Objective: The primary landing page. Must establish immediate trust, provide real-time procurement metrics, and offer an instant keyword search bar.

Content Blocks & Elements:

  • Official Identity Tagline: Badge stating "Jammu & Kashmir Public Works & e-Procurement Directory".
  • Hero Headline & Subtitle: Clear statement about tracking public infrastructure, road macadamization, and civil contracts across all 20 districts.
  • Hero Search Bar: Single-input search box with placeholder "Search tender name, department, or district..." and search button.
  • Quick Search Tags: Clickable filter chips for popular queries (e.g., Civil Works, Jal Shakti / PHE, PMGSY Roads, Electrical Works, Baramulla, Srinagar, Jammu).
  • Live Aggregated Metrics Display (4 Stats):
    • Active Tender Notices count (e.g., 29+ Active Notices)
    • Total Estimated Value in INR (e.g., ₹ 3.01+ Crore)
    • Active State Departments count (e.g., 13+ Departments)
    • Regional Districts count (e.g., All 20 Districts Covered)
  • Active Departments & Sectors Feed / Carousel: Moving ticker or grid showcasing departments, active notice counts, and estimated contract values. Clicking any item navigates directly to the filtered Directory.
  • Recent Tender Announcements: Grid showing 3–4 of the freshest tenders with quick details (ID, Title, Value, Bid End Date).
  • Value Proposition Section: 3 benefit cards explaining zero session timeouts, direct document downloads, and verified site locations.
  • Contractor Call-to-Action (CTA): Banner prompting contractors to create a free account to save notices and receive alerts.
Page 2: Tender Notice Directory
Route: /tenders

Screen Objective: The daily search and filtering command center. Allows contractors to narrow down hundreds of notices using multiple criteria in seconds.

Content Blocks & Elements:

  • Header Area: Page Title, total matching notice count, and a "Reset All Filters" action button.
  • Notice Status Switcher: Tabs to toggle between Active Tenders (currently open for bidding) and Archived Tenders (past notices for price reference).
  • Search & Sort Bar: Keyword input + Sort dropdown (Newest Published, Closing Soonest, Value: High to Low, Value: Low to High).
  • Multi-Dimensional Filters (Sidebar on Desktop, Filter Drawer on Mobile):
    • Districts Filter: All 20 J&K districts (Srinagar, Jammu, Baramulla, Anantnag, Pulwama, Kupwara, Budgam, etc.).
    • Work Category Filter: Civil Works, Electrical Works, Water Equipments/Drilling, Health Supplies, Miscellaneous.
    • Issuing Authority Filter: PWD, Jal Shakti / PHE, DC-PDD, Agriculture, Forest, Shrine Board, Sports Council, etc.
    • Division/Wing Filter: Specific administrative circles (e.g., ED-Anantnag, CAD Pulwama, Directorate of Agriculture).
    • Closing Deadline Filter: Closing in 3 Days (Urgent), 7 Days, 15 Days, 30 Days.
  • Tender Card Component (For Every Result Item):
    • Tender Reference Number and Portal Tender ID (selectable/copyable)
    • Tender Title (concise, high contrast)
    • Department hierarchy (e.g., PWD > R&B Division)
    • Estimated Contract Value in INR (e.g., ₹ 14.50 Lakh)
    • EMD Amount & Tender Document Fee
    • Work Location / District badge
    • Bid Submission Deadline (with urgency indicator for upcoming dates)
    • Action triggers: Save/Bookmark (Heart) and "View Details" button
  • Pagination & Feedback: Numbered pagination controls, loading skeleton states, and an empty state card for "No Tenders Found".
Page 3: Tender Details Deep-Dive
Route: /tenders/:id

Screen Objective: The most crucial decision-making page. Provides complete technical, geographical, financial, and legal specifications for a single tender.

Content Blocks & Layout (2-Column Structure):

Top Header & Actions: Breadcrumbs, Back navigation, Bookmark button, and an "Open Official Portal" helper dialog button.
Sibling Works Banner: For multi-work notices, a carousel of other works published under the same tender notice with individual values.

Left Column (Main Technical Specifications)

  • Basic Details Table: Organisation Chain, Tender Reference Number, Tender ID, Tender Type, Form of Contract, Payment Mode, Technical Evaluation rules.
  • Work Execution Location: Project Site text description, District/City, Pincode, Google Maps search link, Pre-bid meeting venue, and Bid Opening Office.
  • Payment Instruments Table: S.No, Instrument Type (Demand Draft, CDR, FDR, Net Banking, RTGS).
  • Covers Specification Table: Cover 1 (Fee/Technical .pdf), Cover 2 (Finance/BOQ .xls).
  • Mandatory Documents Checklist Table: Required bidder documents (GST certificate, tax clearance, registration card, CDR receipt) with accepted file format.
  • Work Scope & Eligibility: Detailed work scope, contractor registration class required, contract period (in days), bid validity (in days).
  • Tender Inviting Authority: Designation, executive engineer office address, and contact jurisdiction.

Right Column (Financials, Timeline & Vault)

  • Tender Fee & EMD Card:
    • Tender Fee amount, Payable To, Payable At, and Exemption status.
    • EMD Deposit amount, Payable To, Payable At, and Exemption status.
  • Critical Dates Timeline:
    • Published Date & Time
    • Document Download Start & End Date
    • Clarification Start & End Date
    • Bid Submission Start Date
    • Bid Submission Deadline (highlighted)
    • Bid Opening Date & Time
  • Official Document Vault:
    • Official NIT PDF: File name, file size (KB/MB), View in-browser button, and Download button.
    • Work Item BOQ Package (.ZIP): Direct download for the complete official ZIP file.
    • In-Browser ZIP Inspector: Allows contractors to preview files inside the ZIP (BOQ .xls, specifications, drawings) before downloading.

      • Contractor / Business Entity Name
      • Registration Class: Class A Works, Class B, Class C, Class D, Special Class, Electrical Class 1, Hot Mix Plant

    • Tab 3: Filter Preferences & Radar Alerts:
      • Target Work Sectors (multi-select options)
      • Preferred Operating Districts (multi-select options)
      • Minimum Tender Value threshold input/slider
      • Prefer EMD Exemption only toggle
Page 5: Authentication & Onboarding
Route: /login & /signup

Screen Objective: Low-friction, high-trust authentication designed for contractors without complicated password rules.

  • Mode Toggle: Switch between Contractor Login (existing users) and New Registration (new contractors).
  • Passwordless Email OTP Verification:
    • Step 1: User enters email address.
    • Step 2: 6-box individual numeric OTP inputs with 60-second cooldown timer & resend button.
  • One-Click Google Authentication: Fast alternative login using Google.
  • Contractor Onboarding Fields (Signup Mode): Optional collapsible fields to enter Company Name, Registration Class, and Operating District during account creation.
  • Trust & Security Assurance: Institutional note confirming encryption standards.
